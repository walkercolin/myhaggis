    How to play

    Change exactly one letter on every move. Each new combination must be a valid four-letter word, and you cannot reuse a word.

    Par is the shortest possible route from your starting word to POOP. Fewer hints and fewer moves over par rank higher.

    Example
    BOOK → BOOT → BOOT is not allowed because the word did not change. Try BOOK → BOOM instead.
